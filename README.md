# 종이비행기 공중전

색색의 종이비행기를 실제 같은 비행 물리로 모는 3D 공중전입니다. 가로로 든 폰이나 PC 키보드로 하고, 방 번호나 QR로 최대 5명이 함께하며 빈 자리는 봇이 채웁니다. 격추 10점을 먼저 내면 이깁니다.

**플레이:** https://woomars.github.io/paper_airplane_war/

## English

**Paper Plane Dogfight** — a 3D dogfight flying colorful paper planes with true-to-life flight physics. Up to 5 players join by room number or QR; empty seats are bots.

**Play:** https://woomars.github.io/paper_airplane_war/

A personal, non-commercial project. Code and original artwork are under the MIT License ([LICENSE](LICENSE)); everything else follows the licenses and rights listed above. Built with three.js, PeerJS (with webrtc-adapter, sdp, eventemitter3 and peerjs-js-binarypack bundled in) and qrcode-generator. Sound effects and music come from Pixabay (Pixabay Content License) and OpenGameArt (CC0); see [audio/CREDITS.md](audio/CREDITS.md) for each file.
